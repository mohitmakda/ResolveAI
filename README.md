# ResolveAI — v6 cloud candidate

Banking support copilot: TF-IDF + Logistic Regression intent prediction, fictional-policy retrieval, domain/evidence/security guardrails, and human-reviewed response drafting.

**Start:** `python -m streamlit run app.py` after installing `requirements.txt`. See `DEPLOYMENT_GUIDE.md` before publishing.

The current ZIP does not ship BANKING77 and therefore uses a **demo model** until `data/banking77.json` is provided. It has not been publicly deployed or externally validated.
